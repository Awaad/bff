# Schema Integrity Review — Baseline V2.1

**Date:** 2026-09-13  
**Status:** Accepted ACL/semantic hardening

## Runtime role

`bff_runtime_writer` now has explicit admission/config/credential SELECT rights and Execution/Attempt/Idempotency/Usage/Outbox write rights.

## Retention role

`bff_retention` is separate and narrowly delete-capable for purgeable data plus webhook payload-reference purge.

## Future migrations

Migration-owner default privileges prevent accidental invisibility of new tables to control/worker readers. Runtime/retention rights remain explicit and the migration checklist now requires ACL tests.

## Binding identity

`kind` and `exposure_mode` are intentionally immutable identity attributes. Reusing the same Operation under another exposure class creates another Binding.

## No-auth execution

`NONE` is a first-class Credential scheme with no SecretVersion, preserving uniform non-null lineage.
